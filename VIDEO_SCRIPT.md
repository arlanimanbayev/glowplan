# GlowPlan demo video script (about 2 minutes 15 seconds)

**Setup before recording**
- Deploy with both keys set so the top bar shows **YouCam live** and **Gemini planner**. Keep a second tab on a demo-data deployment as a backup.
- Record the phone part on a real phone (screen recording) and the rest on a laptop at 1440 px wide. Light theme for most of it; show dark mode once.
- Use your own face for the live scan, in soft daylight. Clear localStorage first so the check-in step starts clean, or run one live scan the day before so you have a real "before".
- Music: none, or a track you have the rights to. No third-party logos on screen except YouCam / Perfect Corp as the API provider.

**Voice:** calm, plain English, short sentences.
